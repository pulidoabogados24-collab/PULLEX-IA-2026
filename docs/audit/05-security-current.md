# 05 — Seguridad: modelo de amenazas y hallazgos

## Modelo de amenazas (STRIDE simplificado)

**Activos, de mayor a menor valor:** (1) contenido de las conversaciones (consultas jurídicas que pueden contener hechos de casos reales, datos personales y secreto profesional); (2) cuentas y sesiones, en especial la del administrador; (3) clave de API de Anthropic y presupuesto asociado; (4) disponibilidad del servicio e ingresos por plan; (5) reputación jurídica (citas falsas presentadas como verificadas).

**Actores:** estudiante legítimo; **usuario registrado malicioso** (el registro es abierto y gratuito: cualquiera obtiene un token válido en segundos, por eso es el actor más relevante); atacante anónimo en internet; administrador (confiable, pero su navegador es objetivo); proveedor de IA y proveedor de correo (terceros con acceso a datos); contenido externo no confiable (páginas web de la búsqueda, PDFs adjuntos, corpus).

**Fronteras de confianza:** navegador ↔ API (todo lo que llega del cliente es no confiable, incluido `X-Forwarded-For`); API ↔ Anthropic (salen consultas y adjuntos completos); API ↔ Resend (salen correos y nombres); modelo ↔ contenido recuperado (el texto de documentos y web no debe tener autoridad de instrucción); panel admin ↔ datos escritos por estudiantes.

**Superficie de ataque:** 27 rutas HTTP (ver 03), 3 páginas con JS en línea, 2 scripts de CDN, un service worker, el prompt del modelo.
